文件位置

前提条件

1

启用 YouTube Data API v3

🏷️ 规则重标注（retag.py）

基于关键词正则匹配，对 title + description 进行分类，速度快、可解释。已应用于 v3 数据。

文件

/home/claude/youtube/retag.py
输入: eq_children_youtube_v2.csv
输出: eq_children_youtube_v3.csv

运行

python3 /home/claude/youtube/retag.py

分类逻辑

字段逻辑
category检测 title 中的 "read aloud"/"storytime" → read_aloud；检测 "parenting"/"for parents" → parent_guide；检测 "lesson plan"/"classroom" → sel_course；其余默认 children_video
casel_domain对 5 个领域的关键词列表打分，取最高分。无命中则保留原值
problem_tags约 80 个标签，每个对应 2-5 个正则模式，命中则收录
low_quality_flag发布 >1 年 AND view_count <500 AND like_count = 0 → 1

如何调整规则

直接编辑 retag.py 中的 CASEL_RULES、TAG_RULES 列表，添加/修改关键词，然后重新运行脚本生成新版本 CSV。

运行机制

每批 20 个视频，将 title + description(前200字) 拼成 prompt，调用：

📊 数据质量管理

低质量标记逻辑

不直接删除，用 low_quality_flag 列标记（值为 1 / true），由应用层决定是否显示：

# 判断条件（三个同时成立）：
发布时间 > 1年前  AND  view_count < 500  AND  like_count = 0

当前标记了 72 个视频。查询时可过滤：

SELECT * FROM videos WHERE low_quality_flag = false;

数据质量分布（基于 v2 原始数据）

指标数值
中位数 view_count~18,000
view_count > 100万~80 个视频
view_count < 1,000~300 个视频
无 like_count 数据~600 个（YouTube 隐藏）
💡

推荐阈值：view_count > 2,000 作为「基础质量线」筛选，保留主力高质量内容同时不过度删减。

💡

脚本做了什么

CSV 中的字符串字段会自动转换：problem_tags 和 audience 逗号分割为数组；view_count/like_count 解析为 bigint；low_quality_flag "1"/"0" 映射为 boolean；空字符串转为 NULL。

🔍 常用查询示例

按情绪标签推荐（含年龄过滤）

SELECT title, youtube_url, category, casel_domain, view_count
FROM videos
WHERE problem_tags @> ARRAY['anger']        -- GIN 索引
  AND age_min <= 7 AND age_max >= 5
  AND low_quality_flag = false
ORDER BY view_count DESC
LIMIT 10;

按 CASEL 领域 + 受众

SELECT title, channel_name, youtube_url
FROM videos
WHERE casel_domain = 'Self-Management'
  AND audience @> ARRAY['parents']
  AND category = 'parent_guide'
ORDER BY view_count DESC;

标签多选（OR 逻辑）

SELECT title, problem_tags, view_count
FROM videos
WHERE problem_tags && ARRAY['anxiety','worry','fear']   -- 有交集即命中
  AND low_quality_flag = false
ORDER BY view_count DESC LIMIT 20;

➕ 如何继续添加资源

方案 A：添加新 YouTube 查询

1

编辑查询列表

打开 fetch_youtube_sel.py，在 QUERIES 列表末尾添加新的搜索词元组

2

在 Mac 本地运行

方案 B：添加新资源类型（如 App、播客）

方案 C：手工批量添加

准备一个符合 schema 的 CSV（含 video_id 列），直接通过 import_videos_v3.py 导入，或在 Supabase Table Editor 中粘贴。
