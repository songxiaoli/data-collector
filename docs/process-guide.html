🌱 Project Overview

The goal is a curated children's Social-Emotional Learning (SEL) resource library — YouTube videos and picture books — that powers a recommendation system for parents and educators, matching content to a child's emotional challenges, age range, and CASEL domain.

🎬 YouTube Video Collection

Uses the YouTube Data API v3 to bulk-fetch SEL-related videos via keyword search.

Files

FilePurpose
data/scripts/fetch_youtube_sel.pyCollector script (run on your Mac — not in cloud containers)
data/raw/eq_children_youtube_v2.csvRaw output — 2,427 rows, 18 columns

Prerequisites

1

Enable YouTube Data API v3

Go to Google Cloud Console → APIs & Services → search "YouTube Data API v3" → Enable.

2

Create an API Key

Credentials → Create Credentials → API key. Leave IP restrictions off, otherwise local runs may be blocked.

3

Install the client library

pip3 install google-api-python-client (the script also auto-installs it on first run).

⚠️

Important: The YouTube API must be called from your Mac. Cloud container IPs are blocked by Google.

Run

# Run in your Mac terminal
cd ~/Projects/data-collector
YOUTUBE_API_KEY=your_key python3 data/scripts/fetch_youtube_sel.py

🏷️ Rule-based Re-tagging

Keyword regex matching on title + description to fix category, CASEL domain, and problem tags. Fast and fully explainable. Already applied to produce v3.

Files

data/scripts/retag.py
Input:  data/raw/eq_children_youtube_v2.csv
Output: data/raw/eq_children_youtube_v3.csv

Run

python3 data/scripts/retag.py

Logic Summary

FieldLogic
categoryChecks title for "read aloud"/"storytime" → read_aloud; "parenting"/"for parents" → parent_guide; "lesson plan"/"classroom" → sel_course; default → children_video
casel_domainScores each of the 5 domains against keyword lists; picks the highest scorer. Falls back to the original value if nothing matches.
problem_tags~80 tags, each with 2–5 regex patterns. All matched tags are collected.
low_quality_flagPublished >1 year ago AND view_count <500 AND like_count = 0 → 1

Tuning the Rules

Edit CASEL_RULES or TAG_RULES in retag.py, then re-run the script to generate a new versioned CSV.

🤖 LLM Re-tagging

Uses claude-haiku-4-5 to semantically understand each video and re-classify it. Higher accuracy than rules, especially for edge cases.

ℹ️

Current progress: 160 / 2,427 complete. Progress is saved to data/scripts/retag_llm_progress.json — safe to interrupt and resume at any time.

Files

data/scripts/retag_llm.py
Input:  data/raw/eq_children_youtube_v2.csv  (original)
Output: data/raw/eq_children_youtube_v4.csv  (LLM-tagged)

Run (inside a Claude session)

# This script calls the claude CLI — run it inside a Claude conversation session
python3 data/scripts/retag_llm.py
# Automatically resumes from batch 8 (160/2,427 done)
# Estimated remaining time: ~2.5 hours (113 batches × ~80 s/batch)

How It Works

Each batch of 20 videos is assembled into a prompt (title + first 200 chars of description) and sent to:

claude --print --model claude-haiku-4-5 -p "SYSTEM_PROMPT" <<< "batch content"

The JSON response is parsed and category, casel_domain, problem_tags are written to the progress file, then merged into v4.csv at the end.

Re-import v4 to Supabase

SUPABASE_URL=https://nhdswigpkiwbgtxugtmw.supabase.co \
SUPABASE_KEY=your_service_role_key \
CSV_PATH=data/raw/eq_children_youtube_v4.csv \
python3 data/scripts/import_videos_v3.py
💡

The import script uses upsert on_conflict=video_id — safe to re-run; existing rows are updated, no duplicates created.

📊 Data Quality

Low-quality Flag

Videos are flagged rather than deleted, giving the application layer the final say on whether to surface them:

# Flagged when ALL three conditions are true:
published_at older than 1 year  AND  view_count < 500  AND  like_count = 0

72 videos are currently flagged. Filter them in queries:

SELECT * FROM videos WHERE low_quality_flag = false;

Quality Benchmarks (v2 raw data)

MetricValue
Median view_count~18,000
Videos with >1M views~80
Videos with <1,000 views~300
Missing like_count (hidden by YouTube)~600
💡

Recommended threshold: view_count > 2,000 as a baseline quality filter — keeps a healthy high-quality pool without being overly aggressive.

CSV_PATH=data/raw/eq_children_youtube_v3.csv \
python3 data/scripts/import_videos_v3.py

What It Does

Reads the CSV and transforms each row: problem_tags and audience are split on commas into arrays; view_count/like_count are cast to bigint; low_quality_flag "1"/"0" is mapped to boolean; empty strings become NULL. Rows are upserted in batches of 50 on conflict video_id.

🔍 Query Examples

Recommend by emotion tag + age

SELECT title, youtube_url, category, casel_domain, view_count
FROM videos
WHERE problem_tags @> ARRAY['anger']        -- GIN index
  AND age_min <= 7 AND age_max >= 5
  AND low_quality_flag = false
ORDER BY view_count DESC
LIMIT 10;

Filter by CASEL domain + audience

SELECT title, channel_name, youtube_url
FROM videos
WHERE casel_domain = 'Self-Management'
  AND audience @> ARRAY['parents']
  AND category = 'parent_guide'
ORDER BY view_count DESC;

Multi-tag OR match

SELECT title, problem_tags, view_count
FROM videos
WHERE problem_tags && ARRAY['anxiety','worry','fear']   -- any overlap
  AND low_quality_flag = false
ORDER BY view_count DESC LIMIT 20;

➕ Adding More Resources

Option A — Add new YouTube search queries

1

Edit the query list

Open data/scripts/fetch_youtube_sel.py and append new tuples to QUERIES.

2

Run on your Mac

YOUTUBE_API_KEY=xxx python3 data/scripts/fetch_youtube_sel.py → outputs a new v2.csv (auto-deduped).

3

Re-tag

Run retag.py for rules → v3, or wait for LLM tagging to finish and run retag_llm.py → v4.

4

Re-import to Supabase

Run import_videos_v3.py — upsert is safe, no duplicates.

Option B — Add a new resource type (apps, podcasts…)

Create a new Supabase table (e.g. apps) mirroring the same key columns — category, casel_domain, problem_tags text[], age_min/max, audience text[] — so the same recommendation query pattern applies.

Option C — Manual batch import

Prepare a CSV with a video_id column matching the schema and run it through import_videos_v3.py, or paste rows directly into the Supabase Table Editor.
